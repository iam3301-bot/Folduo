# 验证记录

日期：2026-09-16（太平洋时区）。当前开发版本：0.2.2-zh-glass，最新候选 versionCode 49；此前交付版本为 0.2.1-zh-glass，versionCode 44。

## 结论

**code 49 首轮完整 Android 测试为 86 项通过、1 项硬件前提跳过，无失败。随后修正桌面尺寸识别与应用网格列数，构建、JVM 和 Lint 再次通过；相关 9 项 Android 复测全部通过；最终深色安全区域背景修正后构建与 Lint 再次通过。已在模拟器实际检查月白、石墨、晴空配色、全屏应用网格与内外屏排版。最终 APK 已覆盖安装到手机；检查时手机锁屏，服务处于等待解锁状态，尚未完成 code 49 新一轮真机视觉验收。** code 48 已得到本次有限场景的用户确认：“我测试了几次目前正常”，对应三星计算器的开合与画面交接；同次监测末段累计恢复计数为 4，不扩大为全程零故障、所有应用或长期使用均已通过。用户同时表示不喜欢桌面主题，很多应用需要搜索才能找到，code 49 针对这些问题调整桌面入口与外观。

此前尝试保持三星原生桌面的 `native-sharp` 候选未通过视觉验收。用户反馈画面仍不连贯、有瞬间黑屏，停住不动后再动也会黑一下，展开和合上会闪一下壁纸。该路径不再作为 SM-F9760 当前默认方案，也不提供界面上的启用入口。

0.2.1 曾取得连续角度并完成三轮开合的日志检查，但用户随后发现三星主屏幕展开后黑壁纸、外部应用切屏不顺和额外内屏导航条。故障现场曾出现 `idle`、`layers=0`，说明没有残留覆盖层并不能证明壁纸、系统导航和跨应用操作正常。此前把主屏幕问题笼统归为原项目系统界面限制的判断不充分，现已更正。

原壁纸设置与恢复的历史检查仍有效：内外屏桌面使用手机自带的 FoldInteractive，原锁屏壁纸和系统备份保留。本轮未改动壁纸工具。按合上后继续使用的需求，测试手机的三星“在外屏上继续使用应用程序”已从“向上滑动可继续”改为“始终”，对应 `fold_lock_behavior_setting=stay_awake_on_fold_key`。测试期间临时启用的 USB 连接保持唤醒已恢复为原始值 `0`。

## 0.2.2 当前自带桌面方案

当前实施采用固定外屏优先的双屏状态（`OUTER_DEFAULT`），保持物理屏幕布局，并交接前台应用。SM-F9760 使用流光默认桌面，取消原来的大胶囊导航条，改为轻量手势导航。运行期间仍保持双屏；停止或锁屏后释放控制，不承诺在内屏恢复三星完整系统手势与通知面板。

设置引导为 Shizuku → 悬浮显示 → 交互壁纸 → 默认流光桌面 → 启用。code 49 保持这套前提，未更改系统交互壁纸。新桌面包含以下行为，真机体验仍待验收：

- 首页保留 16 个常用位置，其余已安装的可启动应用自动分为后续页，每页 16 个，左右滑动浏览，排除首页已有应用。
- 上滑或点击“全部应用”打开全屏自适应图标网格，默认展示全部应用并支持滚动浏览与搜索。
- 长按后续页或抽屉图标，选择首页位置；已有应用换位置时交换，避免重复，保存的常用位置保留。
- 左下角“桌面外观”选择月白、石墨或晴空，默认月白；保留玻璃材质，不更换提供角度数据的系统壁纸。
- 完全展开或合上的稳定静置状态中，角度超时只重新订阅，不取消当前双屏布局；过渡异常仍保留有界等待与恢复退出。

同次监测记录出现精细角度停止后的自动重订阅，也有应用响应超时恢复；末段累计恢复计数为 4。用户对本次几次操作的正常反馈与这些诊断事件分别保留，不能合并成“全程零故障”。

新一轮真机验收针对流光桌面及从该桌面打开的普通应用，检查展开、合上、停顿再动、反向开合，以及过渡完成后的手势和应用操作。三星原生主屏幕连续动画不再是本轮选定方案的验收目标。仍不能只以角度更新、两块屏幕点亮、返回 `idle` 或 `layers=0` 作为通过条件。

## 壁纸配置与恢复

从本机已安装的三星资源清单选取默认 FoldInteractive，资源名 `video_001.mp4`。工具不包含三星资源文件，也不修改锁屏内容。

- 配置前为内外屏桌面与锁屏建立系统快照。
- 配置后内外屏桌面均为 FoldInteractive，原锁屏编号与有效组件保持一致。
- 在动画运行期间尝试应用配置，工具按预期拒绝，壁纸编号不变。
- 完整执行备份 → 设置 → 恢复，核对原壁纸编号、有效组件、共用关系成功。
- 修复 One UI 共用壁纸在恢复后仍保留锁屏编号、却不返回独立 WallpaperInfo 的识别问题。
- 完成恢复检查后重新备份并设置交互壁纸，最新两份系统快照有效，供日后恢复。

恢复依赖三星快照与手机上的记录文件；未来系统更新或另行换壁纸后需要重新检查。

## 测试边界

标准铰链传感器分辨率为 90°，三星精细传感器需要 signature|privileged 权限，普通 Shizuku shell 无法订阅。因此，当前适配仍依赖原项目的交互壁纸路径。更换普通壁纸后不能维持连续动画。

用户对 code 48 几次计算器开合的确认只覆盖本次场景，不能扩大为所有应用兼容。code 49 已完成排版相关 Android 复测，仍需桌面主题、应用入口和静置后开合的真机验收；原生三星切屏尝试的失败也不能被写成已解决。尚未完成长时间运行、脱离 USB 的长期稳定性、温度和耗电测量、所有第三方应用兼容性及后续 One UI 版本测试。固定双屏方案不提供内屏的完整三星系统手势与通知面板；过渡阶段仍使用静止画面。

仓库图片来自干净模拟器。个人通知、桌面照片、设备序列号、提取的系统文件、签名私钥和个人壁纸恢复记录不进入发布附件。

最终 APK：`Folduo-0.2.2-zh-glass.apk`。签名沿用此前中文版，可直接覆盖安装。
