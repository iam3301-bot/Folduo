## 真机连续角度与开合

系统报告 SM-F9760、Android 17、API 37、One UI 属性 90000；系统版本 CP2A.260605.016.F9760ZCS2AZH8。Shizuku 13.6.0 辅助服务以 UID 2000 工作。

约 220 秒的有效观测片段中，记录到 13,341 条去重后的角度报告、162 个不同角度值，范围 0°—180°。来源为本机三星交互壁纸，包括多个中间角度，能够驱动连续动画，不是仅 0°／90°／180° 的标准姿态数据。

最终 0.2.1 覆盖安装后重新启用，角度持续更新、双屏准备完成，随后再次记录到开合交接。补充检查有 1 次“此系统界面无法像普通应用一样移动”的恢复提示；后续交接恢复、遮罩释放。这是原项目明确不支持系统桌面、最近任务等特殊任务的边界，不能把前述三轮 0 次故障恢复扩大为全部场景没有失败。

以上证明角度输入和画面交接链路完成；没有把日志通过写成用户对动画观感的确认。未逐一验证第三方应用、游戏、视频、银行应用或所有桌面场景。

## 双屏组件与停止检查

实际请求三星并行状态 4（内屏优先）和 5（外屏优先）均成功，两块物理屏幕均报告 ON。外屏捕获为 1080×2520，内屏为 2256×2504；本应用可在 display 0 与 display 1 间移动，目标窗口准备成功。

点击“停止并释放屏幕控制”后，MotionService 消失，current=base=0，无残留 override。此项是真机实际停止检查。

## 壁纸配置与恢复

从本机已安装的三星资源清单选取默认 FoldInteractive，资源名 `video_001.mp4`。工具不包含三星资源文件，也不修改锁屏内容。

- 配置前为内外屏桌面与锁屏建立系统快照。
- 配置后内外屏桌面均为 FoldInteractive，原锁屏编号与有效组件保持一致。
- 在动画运行期间尝试应用配置，工具按预期拒绝，壁纸编号不变。
- 完整执行备份 → 设置 → 恢复，核对原壁纸编号、有效组件、共用关系成功。
- 修复 One UI 共用壁纸在恢复后仍保留锁屏编号、却不返回独立 WallpaperInfo 的识别问题。
- 完成恢复检查后重新备份并设置交互壁纸，最新两份系统快照有效，供日后恢复。

恢复依赖三星快照与手机上的记录文件；未来系统更新或另行换壁纸后需要重新检查。

## 测试边界

标准铰链传感器分辨率为 90°，三星精细传感器需要 signature|privileged 权限，普通 Shizuku shell 无法订阅。因此，当前适配仍依赖原项目的交互壁纸路径。更换普通壁纸后不能维持连续动画。

尚未完成长时间运行、脱离 USB 的长期稳定性、温度和耗电测量、所有第三方应用兼容性及后续 One UI 版本测试。内屏原生导航与通知面板、过渡阶段静止画面的限制沿用原项目。
