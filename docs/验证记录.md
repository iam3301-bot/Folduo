## SM-F9760 真机

- 系统报告型号 SM-F9760，Android 17，API 37，One UI 属性 90000。
- 系统版本 CP2A.260605.016.F9760ZCS2AZH8。
- 中文界面能够安装、启动和显示；修复了初次启动过早访问系统栏控制器导致的异常。
- Shizuku 13.6.0 曾成功启动，辅助服务实际以 UID 2000 连接并完成传感器查询。
- 实际请求三星并行状态 4（内屏优先）与 5（外屏优先）均成功，两块物理屏幕均报告 ON；结束后 current/base 恢复一致，无残留 override。
- 标准铰链传感器 36 可订阅，但分辨率 90°，不足以支撑连续动画。
- 三星传感器 65686 报告 0.01° 分辨率，shell 不具备其所需权限，订阅不可用。权限定义确认为 `com.samsung.permission.SSENSOR`，级别为 `signature|privileged`。另一组折叠状态传感器 65695、65697 及副机身传感器同样需要该权限。
- `dumpsys sensorservice` 中的精细角度事件值显示为 `[value masked]`，不能作为可用角度来源。系统状态诊断与公开输入事件也未提供连续角度。
- 当前壁纸为分层壁纸；没有收到本应用所需的精细角度。
- 保留原桌面及锁屏壁纸，停止后台动画。本次准备的临时系统壁纸备份已清理，没有应用交互壁纸。
