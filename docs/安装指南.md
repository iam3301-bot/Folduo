# 折叠流光 · 中文玻璃版

面向三星 Galaxy Z Fold8 Ultra（SM-F9760）和 One UI 9.0。安装包的应用名称是“折叠流光”，基于 [Folduo](https://github.com/bunkaich/Folduo) 修改。

## 安装

从本仓库的 [发布页面](https://github.com/iam3301-bot/Folduo/releases) 下载 APK，在手机上打开安装。首次安装时，如系统提示，请为打开安装包的“我的文件”或浏览器允许安装未知应用。

本版本使用独立包名 `io.github.iam3301.folduo` 和独立签名，可与原版共存。原版和其他折叠动画工具应先停止屏幕控制，再启动本版本。

也可以通过已授权的 USB 调试安装：

```sh
adb install -r Folduo-0.2.0-zh-glass.apk
```

## 先体验中文界面

- **流光**：查看动画状态、预览折叠效果、打开流光桌面。
- **外观**：调整玻璃浓度；控制按压缩放效果。更改自动保存。
- **设置**：连接 Shizuku、管理悬浮显示、启用或停止动画、查看传感器诊断。

首次启动默认简体中文，不受手机系统语言影响。需要其他语言时，在“设置 → 界面语言”中选择。桌面上的第三方应用名称由相应应用提供。

## 当前交付状态

本次选择保留手机现有壁纸，先交付中文界面。因此后台折叠动画保持关闭，可直接使用玻璃外观设置、效果预览和可选桌面。无需再开合手机或继续设置调试。

## 后续启用折叠动画的条件

1. 安装并启动 [Shizuku](https://shizuku.rikka.app/zh-hans/guide/setup/)。可以用无线调试或电脑启动；手机重启后需要重新启动 Shizuku。
2. 在本应用“设置”中连接 Shizuku，并在授权提示中允许访问。
3. 允许悬浮显示和通知。
4. 先运行“检测传感器”。双屏状态必须可用，开合过程中需要持续的精细角度。只有 0°、90°、180° 的姿态数据不够。
5. 阅读临时读取屏幕的说明，轻触“同意临时读取屏幕并启用”。解锁后完全合上手机一次，再缓慢展开。

SM-F9760 已加入型号检查，但三星双屏状态、私有接口和壁纸行为仍以真机检测为准。如果系统缺少所需的并行状态，本应用会显示中文原因并停止控制。**APK 可安装、界面可运行，不等于实际折叠动画已验证。** 当前验证结果见 [验证记录](验证记录.md)。

### 壁纸与精细角度

实测这台 SM-F9760 的标准角度传感器分辨率为 90°；三星精细角度传感器需要未向 shell 开放的权限。当前分层壁纸没有提供应用所需的角度数据。

本机自带 FoldInteractive 组件及折叠交互壁纸资源。已适配 One UI 9.0 新的日志格式，但没有更换壁纸，也没有验证该来源的连续角度和实际双屏动画。不应将解析器测试通过视为真实开合已通过。

如果真机有可用的精细角度传感器，会优先使用传感器；壁纸读取是后备来源。如果缺少精细角度，需要先核实当前系统的交互壁纸。仓库内的 `cover-wallpaper.py` 仍只允许原作者验证过的 SM-F966Z，不能用于给 SM-F9760 强制设置壁纸。

### 只读设备检查

连接手机并允许 USB 调试后，可运行：

```sh
python3 tools/device-check.py --output device-report.json
```

报告包含型号、系统、并行屏幕状态和角度传感器摘要，不保存设备序列号或屏幕画面，不修改壁纸、不切换屏幕。开启动画后的动态角度和屏幕交接仍需另外测试。

## 日常操作

内屏导航条提供最近任务、主屏幕、返回和设置；外屏沿用三星导航。内屏原生手势和通知面板仍受原项目方案限制。

运行时两块屏幕会同时点亮，耗电增加。过渡阶段使用短暂静止画面，视频和游戏不会在这张画面中继续播放；应用准备好后恢复实时显示。画面仅在内存中使用，不保存、不上传。

停止时在设置中选择“停止并释放屏幕控制”。建议先停止，再卸载。若画面或导航卡住，先完全合上手机，从外屏停止；无法操作时可重启手机。

## 源码与构建

需要 JDK 17 或兼容版本、Android SDK 37、build-tools 36.0.0。仓库自带 Gradle 9.5.1 包装器。

```sh
sdkmanager "platforms;android-37.0" "build-tools;36.0.0" "platform-tools"
python3 tools/check-chinese.py
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintRelease
```

调试 APK 使用本地 `.local-signing/debug.keystore`。正式签名在仓库外管理：设置 `FOLDUO_SIGNING_DIR`，目录内放置 `folduo-release.jks` 和 `password.txt`，别名为 `folduo`，再构建 `:app:assembleRelease`。未提供签名目录时，release 为未签名包，不能直接安装。私钥和口令不上传到 GitHub。

视觉材质参考 [苹果 iOS 27 的 Liquid Glass](https://www.apple.com/os/ios/)：清晰的文字、可调浓度、边缘折射与柔和高光。实现使用 Android 原生视图和 RuntimeShader，不包含苹果或三星的专有视觉素材。
