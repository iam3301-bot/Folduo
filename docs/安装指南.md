# 折叠流光 · 中文玻璃版

当前候选为 **0.2.3-zh-glass／code 50（文件夹与连接恢复，已安装验证）**，面向三星 Galaxy Z Fold8 Ultra（SM-F9760）／One UI 9.0。应用名称为“折叠流光”，基于 [Folduo](https://github.com/bunkaich/Folduo) 修改。继续使用流光默认桌面与双屏并行。本轮构建、自动化和模拟器文件夹检查已完成，候选已同签名覆盖安装。初次安装检查时手机锁屏，服务等待解锁；随后解锁触发的超时自动恢复已在真机完成，角度输入与双屏布局恢复。实际开合效果仍待用户确认。

## 已配置的这台手机

已按原项目要求配置本机三星交互壁纸。内外屏桌面使用深灰色折叠交互效果，原锁屏壁纸保留；原壁纸的系统备份仍在手机上，设置与恢复工具此前完成真机往返检查。本轮不更换壁纸，也未改动工具。

按合上后继续使用的需求，测试手机的三星“在外屏上继续使用应用程序”已设为“始终”。当前使用用户选定的流光默认桌面与固定双屏方案，不再提供原生三星切屏试验入口。code 48 的几次计算器开合曾获用户反馈正常，但监测也有自动恢复事件。code 49 已安装并发布为验证版，用户随后反馈无动画；本轮确认辅助服务启动失败，打开 Shizuku 管理器后连接与角度输入恢复，视觉效果仍需重新检查，详见[验证记录](验证记录.md)。

## 首次完整配置

已配置的手机无需重复执行以下壁纸步骤。重新配置或在另一台同型号设备使用时，按顺序操作。

1. 安装并启动 [Shizuku](https://shizuku.rikka.app/zh-hans/guide/setup/)，使用无线调试或电脑启动均可。
2. 连接已允许 USB 调试的 SM-F9760，先在“折叠流光 → 设置”中停止动画。
3. 从发布页下载并解压 `Folduo-Fold8-wallpaper-tools-0.2.1.zip`。电脑需要 Python 3 和 Android platform-tools（ADB），在解压目录运行：

```sh
python3 fold8-wallpaper.py status
python3 fold8-wallpaper.py prepare
python3 fold8-wallpaper.py apply
```

`prepare` 备份内外屏桌面与锁屏；`apply` 将两块屏幕的桌面设置为本机默认交互资源，保留锁屏。工具从手机已安装的资源清单读取参数，本次 SM-F9760 使用 `video_001.mp4`，不照搬 Fold7 的资源编号。不分发三星壁纸文件。ADB 不在 PATH 时加 `--adb /完整路径/adb`，连接多台设备时加 `--serial 目标序列号`。

4. 打开“折叠流光 → 设置”，连接 Shizuku，在授权提示中允许访问，并允许悬浮显示及通知。
5. 若要合上后继续显示外屏，将三星“在外屏上继续使用应用程序”设为“始终”。这是系统设置，安装 APK 不会自动修改。
6. 在“折叠流光 → 设置 → 设置流光桌面”轻触“设为默认桌面”，在系统选项中选择“折叠流光”。当前方案按这一默认桌面配置使用。
7. 完成以上步骤后，轻触“同意临时读取屏幕并启用”。保持解锁，先完全合上一次完成初始化，再缓慢展开与合上；运行状态应显示“原生交互壁纸”角度。该状态只能确认角度来源，还需实际检查流光桌面的过渡连续性和完成后的应用操作。

工具只接受 SM-F9760，并检查原壁纸编号及备份是否有效。如果壁纸在配置后又被手动更换，工具会拒绝覆盖。仓库中的 `cover-wallpaper.py` 保留给原版 Fold7 使用，不能代替 Fold8 工具。

## 日常使用

- **流光**：查看状态、预览折叠效果、打开当前方案使用的流光桌面。
- **外观**：调整玻璃浓度与按压动态效果，更改自动保存。
- **设置**：先连接 Shizuku、允许悬浮显示与准备壁纸，再设定默认桌面，最后启用／恢复动画；也可停止并释放屏幕控制。

首次启动默认为简体中文，第三方应用名称由相应应用提供。当前完整开合方案使用折叠流光作为默认桌面。

- **直接找应用**：首页保留 16 个常用位置；左右滑动可浏览其余已安装的可启动应用，每页 16 个，首页已有的应用不会在后续页重复出现。无需先搜索才能打开应用。
- **浏览全部应用**：在桌面上滑或点击“全部应用”，进入全屏图标网格。网格随内外屏宽度调整列数，默认展示全部应用，可上下滚动；需要时再输入名称搜索。
- **整理首页**：长按后续页或“全部应用”中的图标，选择首页的一个位置；若同一应用已在首页，会交换它与目标位置的内容。长按首页图标可更换该位置的应用，原有常用位置在更新后保留。
- **更换配色**：点击桌面左下角“桌面外观”，选择“月白 · 简洁浅色”“石墨 · 深色玻璃”或“晴空 · 蓝色玻璃”。默认使用月白，选择自动保存。这里只改变流光桌面的外观，保留玻璃材质与系统交互壁纸，不影响壁纸提供精细角度。

若要返回三星主屏幕，先停止动画，再在系统的默认应用设置中选择 One UI 主屏幕。

手机重启后需要重新启动 Shizuku，再在应用中恢复动画。Shizuku 停止后动画也会停止。若显示辅助服务启动超时，可先打开 Shizuku 管理器，确认服务运行与本应用授权，再回到“折叠流光 → 设置”恢复动画；本轮现场这样恢复了连接，但仍需实际开合确认效果。若画面或导航卡住，先完全合上，从外屏停止动画；无法操作时重启手机。

0.2.3 增加启动失败的自动恢复：已有授权但绑定超时后，仅移除本应用的旧辅助服务记录并清理本地回调，限频通过后台广播唤醒 Shizuku 管理器，等待完成后再绑定。本次真机先完成了直接重连，随后再次覆盖安装实际触发 provider 不可用及启动超时；解锁后由本应用发送后台广播并恢复辅助服务，无需手工打开管理器。该过程已由普通应用权限下的日志验证，实际开合观感仍待确认。Shizuku 本身仍需运行并完成首次授权。

更新后回到流光桌面时，如果用户原先已经启用动画、但动画服务没有运行，桌面会恢复服务；用户在设置中主动停止后不会自动重新开启。本轮已用专项测试验证两种情况。

最近任务等特殊系统界面不按普通应用处理，未完成全部场景验证；三星原生主屏幕的连续动画不属于本轮选定方案。

当前方案运行期间保持双屏并行，并在内外屏之间交接应用；停止动画或锁屏后释放控制。SM-F9760 的内屏改用轻量手势导航，不显示原来的大胶囊导航条；外屏沿用三星导航。内屏不恢复三星通知面板或完整原生手势。双屏运行会增加耗电，尚未进行长期测量。code 49 在完全展开或合上的稳定静置状态下重订阅角度时保留双屏布局，过渡中发生异常仍会超时恢复退出；该调整尚待真机验收。

过渡使用短暂静止画面，视频和游戏在过渡画面中不会继续播放。受保护的画面不捕获。画面仅在内存中使用，不保存、不上传。

## 文件夹操作（0.2.3）

文件夹用于把多个应用归到一个首页入口，保留原有 16 个首页位置、应用分页、全部应用和三种配色。本版使用长按菜单管理文件夹；自动化检查与模拟器操作已完成，本机日常使用体验仍待确认。

1. 长按首页任一应用，选择“建立文件夹”，勾选至少两个应用后点击“建立文件夹”。默认名为“文件夹”，创建后自动打开。
2. 点击桌面的组合图标，进入全屏应用网格；点击其中的应用即可启动。
3. 在打开的文件夹中，点击标题或底部“重命名”修改名称，点击“整理应用”多选增删成员，点击“解散文件夹”撤销分组。也可长按桌面文件夹使用同名菜单。
4. 长按后续页或“全部应用”中的应用，选择首页位置时，已有文件夹会显示“位置 N · 加入‘名称’文件夹”，选择它即可添加成员。

将应用加入文件夹会清空它原来的首页位置；若它属于另一文件夹，会移入新文件夹。其余首页位置保持不动。移除的成员回到后续应用页和“全部应用”；解散时按成员原顺序放回空闲首页位置，放不下的应用留在后续页。模拟器已实际创建包含相机、文件和相册的文件夹；切换内外屏布局、关闭并重新打开、强制停止后重新进入，成员顺序保留。点击“文件”实际启动了系统文件应用。这些检查不代替三星真机开合验收。

## 恢复原壁纸

先点击“停止并释放屏幕控制”，再连接电脑，在解压的工具目录运行：

```sh
python3 fold8-wallpaper.py restore
```

本次真机已验证：原内外屏壁纸编号、组件及桌面与锁屏的共用关系恢复正确。三星会在成功恢复后消耗该次快照；再次设置时重新执行 `prepare`、`apply`。

恢复依赖手机上的系统快照，以及 `/data/local/tmp/folduo-fold8-wallpaper-state` 记录。不要清理这份记录；卸载应用不会自动恢复壁纸。系统升级、重置或手动换壁纸可能使旧快照失效，工具会停止并提示检查。

## 源码与构建

需要 JDK 17 或兼容版本、Android SDK 37、build-tools 36.0.0，仓库包含 Gradle 9.5.1 包装器。

```sh
sdkmanager "platforms;android-37.0" "build-tools;36.0.0" "platform-tools"
python3 tools/check-chinese.py
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintRelease
python3 tools/build-fold8-wallpaper-helper.py --sdk /完整路径/android-sdk
```

源码目录运行壁纸工具时，在文件名前加 `tools/`。调试 APK 使用本地 `.local-signing/debug.keystore`。正式签名保存在仓库外：设置 `FOLDUO_SIGNING_DIR`，其中放置 `folduo-release.jks` 和 `password.txt`，别名为 `folduo`，再构建 `:app:assembleRelease`。未设置签名目录的 release 包未签名，不能直接安装。私钥与口令不上传。

只读设备检查可运行 `python3 tools/device-check.py --output device-report.json`。该报告不能代替实际开合测试。

界面材质参考 [Apple Liquid Glass](https://www.apple.com/os/ios/)，使用 Android 原生视图与 RuntimeShader 实现边缘折射、柔和高光、透明层次和可调浓度，不包含苹果或三星专有素材。测试范围见 [验证记录](验证记录.md)。
