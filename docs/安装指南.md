# 折叠流光 · 中文玻璃版

版本 **0.2.1-zh-glass**，面向三星 Galaxy Z Fold8 Ultra（SM-F9760）／One UI 9.0。应用名称为“折叠流光”，基于 [Folduo](https://github.com/bunkaich/Folduo) 修改。

## 已配置的这台手机

已按原项目要求配置本机三星交互壁纸。内外屏桌面使用深灰色折叠交互效果，原锁屏保留；原壁纸的系统备份仍在手机上。动画、停止并释放屏幕控制、壁纸恢复均完成真机检查。日常使用保留这套桌面壁纸，手机重启后重新启动 Shizuku，再恢复动画。

## 安装包

从 [0.2.1 发布页](https://github.com/iam3301-bot/Folduo/releases/tag/v0.2.1-zh-glass) 下载 `Folduo-0.2.1-zh-glass.apk`。手机打开 APK 安装；系统提示时，为“我的文件”或浏览器允许安装未知应用。已安装旧中文版可直接覆盖更新。

独立包名 `io.github.iam3301.folduo`、独立签名，可以与原版共存。启用前先停止其他折叠动画工具。电脑安装命令：

```sh
adb install -r Folduo-0.2.1-zh-glass.apk
```

## 首次完整配置

已配置的手机无需重复执行以下壁纸步骤。重新配置或在另一台同型号设备使用时，按顺序操作。

1. 安装并启动 [Shizuku](https://shizuku.rikka.app/zh-hans/guide/setup/)，使用无线调试或电脑启动均可。
2. 连接已允许 USB 调试的 SM-F9760，先在“折叠流光 → 设置”中停止动画。
3. 从发布页下载并解压 `Folduo-Fold8-wallpaper-tools-0.2.1.zip`。电脑需要 Python 3 和 Android platform-tools（ADB），在解压目录运行：

```sh
python3 fold8-wallpaper.py status
python3 fold8-wallpaper.py prepare
python3 fold8-wallpaper.py apply
```

`prepare` 备份内外屏桌面与锁屏；`apply` 将两块屏幕的桌面设置为本机默认交互资源，保留锁屏。工具从手机已安装的资源清单读取参数，本次 SM-F9760 使用 `video_001.mp4`，不照搬 Fold7 的资源编号。不分发三星壁纸文件。ADB 不在 PATH 时加 `--adb /完整路径/adb`，连接多台设备时加 `--serial 目标序列号`。

4. 打开“折叠流光 → 设置”，连接 Shizuku，在授权提示中允许访问，并允许悬浮显示及通知。
5. 轻触“同意临时读取屏幕并启用”。保持解锁，完全合上一次，再缓慢展开。运行状态应显示“原生交互壁纸”角度。

工具只接受 SM-F9760，并检查原壁纸编号及备份是否有效。如果壁纸在配置后又被手动更换，工具会拒绝覆盖。仓库中的 `cover-wallpaper.py` 保留给原版 Fold7 使用，不能代替 Fold8 工具。

## 日常使用

- **流光**：查看状态、预览折叠效果、打开可选的流光桌面。
- **外观**：调整玻璃浓度与按压动态效果，更改自动保存。
- **设置**：连接 Shizuku、启用／恢复动画、停止并释放屏幕控制。

首次启动默认为简体中文，第三方应用名称由相应应用提供。使用动画不需要更换默认桌面，流光桌面是可选项。

手机重启后需要重新启动 Shizuku，再在应用中恢复动画。Shizuku 停止后动画也会停止。若画面或导航卡住，先完全合上，从外屏停止动画；无法操作时重启手机。

系统桌面、最近任务及其他系统界面不按普通应用任务处理，不保证跨屏动画；实测补充检查中曾出现对应提示并恢复。不要把此类界面的行为当作普通应用的兼容性。

内屏显示原项目的自定义导航，外屏沿用三星导航。内屏的原生手势、通知和快捷设置面板仍有原项目方案的限制。运行时两块屏幕同时点亮，会增加耗电；过渡使用短暂静止画面，视频和游戏在过渡画面中不会继续播放。受保护的画面不捕获。画面仅在内存中使用，不保存、不上传。

## 恢复原壁纸

先点击“停止并释放屏幕控制”，再连接电脑，在解压的工具目录运行：

```sh
python3 fold8-wallpaper.py restore
```

本次真机已验证：原内外屏壁纸编号、组件及桌面与锁屏的共用关系恢复正确。三星会在成功恢复后消耗该次快照；再次设置时重新执行 `prepare`、`apply`。

恢复依赖手机上的系统快照，以及 `/data/local/tmp/folduo-fold8-wallpaper-state` 记录。不要清理这份记录；卸载应用不会自动恢复壁纸。系统升级、重置或手动换壁纸可能使旧快照失效，工具会停止并提示检查。

## 源码与构建

需要 JDK 17 或兼容版本、Android SDK 37、build-tools 36.0.0，仓库包含 Gradle 9.5.1 包装器。

```sh
sdkmanager "platforms;android-37.0" "build-tools;36.0.0" "platform-tools"
python3 tools/check-chinese.py
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintRelease
python3 tools/build-fold8-wallpaper-helper.py --sdk /完整路径/android-sdk
```

源码目录运行壁纸工具时，在文件名前加 `tools/`。调试 APK 使用本地 `.local-signing/debug.keystore`。正式签名保存在仓库外：设置 `FOLDUO_SIGNING_DIR`，其中放置 `folduo-release.jks` 和 `password.txt`，别名为 `folduo`，再构建 `:app:assembleRelease`。未设置签名目录的 release 包未签名，不能直接安装。私钥与口令不上传。

只读设备检查可运行 `python3 tools/device-check.py --output device-report.json`。该报告不能代替实际开合测试。

界面材质参考 [Apple Liquid Glass](https://www.apple.com/os/ios/)，使用 Android 原生视图与 RuntimeShader 实现边缘折射、柔和高光、透明层次和可调浓度，不包含苹果或三星专有素材。测试范围见 [验证记录](验证记录.md)。
